# DASHKA WIRE

Личное утреннее издание Дарьи Беленковой: [открыть сайт](https://darabelenkova1286-tech.github.io/).

Здесь лежит опубликованный статический сайт. Редакторский код и черновики находятся в отдельном репозитории `darabelenkova1286-tech/dashka-wire`. Основа проекта — [ADanMan/frontier-wire](https://github.com/ADanMan/frontier-wire), лицензия MIT.

В выпуске есть подробные статьи и короткая лента других проверенных новостей без фиксированного лимита. У каждой заметки указаны дата события, ссылка на публикацию и первоисточник; машинная версия находится в `wire/<дата>.json` и `feed.json`.

Ниже выпуска сайт показывает **все публикации, которые сборщик обнаружил на прямых страницах перечисленных источников с момента запуска**. Этот поток хранится в `source-stream.json` и обновляется каждый час workflow `.github/workflows/source-stream.yml`, без RSS. Для TechCrunch и Futurism дополнительно проверяются их карты новостей. В ленте сохранены исходные заголовки и прямые ссылки. Они ещё не прошли редакторскую проверку: дата публикации указывается только если источник её предоставляет, иначе отображается время обнаружения. Состояние каждого источника видно на сайте; при 403, таймауте или неполной странице охват может быть неполным. В Telegram сборщик листает публичную веб-историю до уже известной публикации, максимум 10 страниц за запуск.

У каждой новости есть шкала личной релевантности от 0 до 10. Оценки хранятся в `localStorage` этого браузера под ключом `dw-feedback-v1`. Режим «Для меня» сортирует ленту по оценкам публикаций, тем и источников. Локальная утренняя задача Codex читает эти оценки перед редакторским отбором, если имеет доступ к тому же in-app браузеру. Оценки не отправляются в публичный репозиторий и не синхронизируются между устройствами.

## Утренняя рассылка

Workflow `.github/workflows/morning-delivery.yml` проверяет наличие сегодняшнего выпуска по Москве при публикации и в 08:00, 09:00, 10:00. Если выпуск вышел, отправляет его в подключённые каналы и записывает маркеры `.delivery/`, чтобы повторный запуск не дублировал письмо или сообщение. Почта и Telegram настраиваются отдельно. Если нового выпуска сегодня нет, рассылка ничего не отправляет.

Для включения откройте **Settings → Secrets and variables → Actions → New repository secret** и добавьте:

| Secret | Значение |
| --- | --- |
| `SMTP_USER` | Адрес Gmail отправителя |
| `SMTP_PASSWORD` | Пароль приложения Google для этого аккаунта |
| `MAIL_TO` | Адрес получателя |
| `TELEGRAM_BOT_TOKEN` | Новый токен бота после перевыпуска в BotFather |
| `TELEGRAM_CHAT_ID` | Числовой ID личного чата после команды `/start` боту |

Токены и пароли не добавляйте в файлы репозитория или в чат. Telegram можно проверить сразу: **Actions → DASHKA WIRE morning delivery → Run workflow → test_telegram**. Обычный запуск до первого выпуска безопасно ничего не отправляет.
